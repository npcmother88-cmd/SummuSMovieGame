# 🎬 Poorly Described Movies

A movie guessing game created for **Summus Guild**.

Players are given hilariously bad descriptions of movies and have to figure out which movie is being described.

## 🍿 How to Play

The game has four rounds:

- **Easy** — 1 point each
- **Medium** — 2 points each
- **Hard** — 3 points each
- **Bonus** — 5 points each

Read the poorly described movie, make your guess, and then reveal the answer.

The game keeps track of your score automatically.

## 🎲 Replayability

Each new game randomly selects questions from a larger movie bank, so you won't necessarily get the same game every time.

Movies include everything from:

- Horror
- Comedy
- Action
- Disney & animation
- 80s and 90s movies
- Classics
- Cult favorites
- Modern movies

## 🏆 The Goal

Know movies.

Survive the terrible descriptions.

And try not to yell:

**“OH COME ON, I SHOULD HAVE KNOWN THAT!”**
